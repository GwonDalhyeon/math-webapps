# 카피바라 AI 이미지 메모

- 현재 게임 파일: `assets/capybara-ai-cute-sample.png`
- 이전 시안: `assets/capybara-ai.png`
- 제작 방식: OpenAI 내장 이미지 생성 도구로 새로 생성한 독자적인 게임 캐릭터
- 참고 범위: 사용자가 제시한 이미지에서는 일반적인 카피바라 체형과 여러 자세라는 아이디어만 확인했다.
- 비사용 범위: 워터마크가 있는 첨부 이미지의 픽셀, 윤곽선, 자세 배열, 워터마크는 복사하거나 편집하지 않았다.
- 후처리: 단색 크로마키 배경을 로컬에서 제거하고 투명 PNG로 저장했다.
- 생성 프롬프트 요약: 왼쪽을 바라보며 앞발을 든, 작은 점눈과 둥근 몸을 가진 따뜻한 갈색의 독자적인 2D 카피바라 배구 캐릭터.
