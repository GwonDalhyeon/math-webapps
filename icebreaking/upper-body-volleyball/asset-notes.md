# 카피바라 AI 이미지 메모

## 대기 자세

- 게임 파일: `assets/capybara-ai-cute-sample.png`
- 제작 방식: OpenAI 내장 이미지 생성 도구로 새로 생성한 독자적인 게임 캐릭터
- 참고 범위: 사용자가 제시한 이미지에서는 일반적인 카피바라 체형과 여러 자세라는 아이디어만 확인했다.
- 비사용 범위: 워터마크가 있는 첨부 이미지의 픽셀, 윤곽선, 자세 배열, 워터마크는 복사하거나 편집하지 않았다.
- 후처리: 단색 크로마키 배경을 로컬에서 제거하고 투명 PNG로 저장했다.
- 생성 프롬프트 요약: 왼쪽을 바라보며 앞발을 든, 작은 점눈과 둥근 몸을 가진 따뜻한 갈색의 독자적인 2D 카피바라 배구 캐릭터.
- 이전 시안 `assets/capybara-ai.png`는 쓰지 않아 2026-11-21에 지웠다.

## 득점·실점 반응 자세 (2026-11-21 추가)

| 파일 | 상태 | 자세 |
|---|---|---|
| `assets/capybara-score-tongue.png` | 카피바라 득점 | 실눈으로 혀를 내미는 메롱 |
| `assets/capybara-score-smug.png` | 카피바라 득점 | 코를 치켜들고 앞발을 배에 올린 으쓱 |
| `assets/capybara-score-dopey.png` | 카피바라 득점 | 멍한 얼굴로 앞발을 살짝 든 만세 |
| `assets/capybara-score-wiggle.png` | 카피바라 득점 | 곁눈질하며 엉덩이 흔들기 |
| `assets/capybara-score-shrug.png` | 카피바라 득점 | 무표정한 어깨 으쓱 |
| `assets/capybara-lose.png` | 카피바라 실점 | 축 처진 몸, 땀방울, 꼬인 선 |

- 제작 방식: 대기 자세 그림(위의 독자 캐릭터)을 참조 이미지로 첨부해 Codex 내장 이미지 생성 도구로 같은 캐릭터의 자세만 바꿔 그렸다.
- 생성 조건: 자홍(#FF00FF) 단색 배경, 왼쪽을 바라봄, 눈 하이라이트·옷·소품 없음, 그림 안에 글자 없음. 말풍선 문구는 게임 코드(`CAPYBARA_LINES`)에서 그린다.
- 검수: 다리 4개, 귀·눈 개수, 앞발 모양을 확인했다. 득점 만세 자세는 앞발이 길쭉하게 나와 1회 다시 생성했다.
- 후처리: 자홍 배경을 로컬에서 제거하고, 긴 변 480px·128색 팔레트 PNG로 줄였다(한 장 13~30KB).
