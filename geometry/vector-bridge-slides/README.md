# 벡터로 읽는 구조물 — 수업 슬라이드

기하의 평면벡터를 구조물의 힘 해석과 연결하는 교사용 투사 화면이다. 4:3, 1024×768을 기준으로 만들었으며 빌드 없이 정적 웹 서버에서 실행한다.

| 파일 | 내용 | 화면 수 |
|---|---|---:|
| `00-prep.html` | 힘을 벡터로 나타내기 | 28 |
| `01-build.html` | 구조물 제작 | 12 |
| `02-analysis.html` | 해석과 예측·실험 | 9 |
| `03-verify.html` | 검증과 개선 | 8 |

`index.html`에서 차시를 선택한다. 방향키·스페이스·화면 밀기로 진행하고, 풀이 칸은 개별로 누르거나 화면 위 도구로 연다. `B`는 화면 끄기, `Esc`는 전체 화면 목록이다. 활동 시계는 숫자를 눌러 시작·멈춤하고 `↺`로 다시 맞춘다. 새 활동 시작 화면에 들어가면 해당 활동의 기본 시간으로 초기화된다.

웹 서버에서 열면 삽화의 움직임을 사용할 수 있다. WebGL을 사용할 수 없거나 파일을 직접 열면 원래 그림을 표시한다. 라이브러리와 글꼴은 이 폴더에 포함한다.

이 배포본은 학습지 최종본(v0.8)에 맞춰 2026-10-19에 전수 점검한 57장 화면을 옮긴 것이다. 평가 원본, 교사용 예시답안·채점 자료, 개인정보, 제작 도구, 시안과 검토 캡처는 포함하지 않는다. 0차시에는 수업 중 함께 푸는 연습 예제의 풀이가 들어 있으며, 1–3차시에는 평가 과제의 정답·풀이 단서·개선 예시를 화면과 발표자 노트에 넣지 않았다.

수업 전에는 제작 재료·실험 조건과 접속할 웹앱의 운영 기준을 학습지와 함께 맞추고 실제 투사 기기에서 확인한다. 이 화면은 별도 평가 웹앱의 배포·계정 준비 완료를 보장하지 않는다.
