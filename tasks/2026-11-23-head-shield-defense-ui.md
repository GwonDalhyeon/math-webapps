# 머리로 막아! 꼬물이 지키기 — UI 상세 설계

웹앱 위치: `icebreaking/head-shield-defense/index.html`
이미지 제작 매니페스트: [`2026-11-23-head-shield-defense-art-manifest.md`](./2026-11-23-head-shield-defense-art-manifest.md)

대상: 일반계 고등학교 전체 학생, 첫 수업·모둠 활동 아이스브레이킹
기기 기준: iPad A16 가로 `1180×820` CSS px 우선, 세로 `820×1180`도 깨지지 않을 것. 교실 프로젝터/전자칠판 공유.

## 0. 이 설계가 바꾸는 것

| 항목 | 이전 | 이번 설계 |
|---|---|---|
| 머리 판정 원 | 중립 위치 대비 2.1~2.5배 증폭해 둥지 둘레에 따로 그림 | **카메라 영상 속 실제 머리 위에 1:1로** 그림. 보이는 원 = 판정 원 |
| 둥지 위치 | 화면 정중앙 (머리와 겹침) | **하단 중앙(세로 76%)**, 학생의 가슴 앞. 머리는 항상 그 위쪽 |
| 공 생성 | 화면 밖에서 소리 없이 생김 | **가장자리의 투척 캐릭터가 조준 → 던지는 동작**으로 손에서 생성 |
| 목표 | 오래 버티기(끝 없음) | **제한 시간을 버티면 부화 → 다음 단계**. 단계 보너스가 점수의 중심 |
| 지킬 대상 | 무표정한 알 | **꼬물이** — 숨 쉬고, 공을 눈으로 따라보고, 자라고, 3단계부터 도와줌 |

핵심 의도: "가만히 있으면 안 막힌다"와 "다음 공이 어디서 오는지 미리 보인다"를 **규칙 설명이 아니라 화면으로** 전달한다.

## 1. 화면 전체 구조 (한 화면, 스크롤 없음)

```text
┌ 상단 바 (min-height 62px, 흰 배경, 아래 2px 테두리) ───────────────────────┐
│ ← 아이스브레이킹   머리로 막아! 꼬물이 지키기        [소리 끄기] [Ⅱ 일시정지] │
├ 무대 stage (남은 높이 전부, 반지름 22px, 카메라 영상이 비율 유지로 깔림) ──┤
│  ◤요정A                   ▲요정B                   요정C◥                  │
│   ┌점수 1,240┐      ┌ 부화까지 23.4초 ───────┐      ┌콤보 7┐               │
│   └──────────┘      │▓▓▓▓▓▓▓▓▓░░░░░░░░░░░░░░│      └──────┘               │
│                     │   2단계 · 알 ●●○      │                             │
│  ◀요정D             └───────────────────────┘             요정E▶          │
│                                                                           │
│                          ◯  ← 머리 원 (영상 속 머리 위, 1:1)               │
│                                                                           │
│                        🥚 둥지 + 꼬물이 (가로 중앙, 세로 76%)              │
└───────────────────────────────────────────────────────────────────────────┘
```

좌표계는 **무대 높이를 1로 보는 단위계**를 쓴다. x는 0~화면비(aspect), y는 0~1. 가로로 긴 화면에서도 원이 찌그러지지 않는다.

레이어 순서(아래→위): 카메라 영상 → 어둡게 덮는 막(투명도 34%) → 동심원 안내선 → 둥지·꼬물이 → 공 → **투척 요정** → 머리 원 → 파티클 → HTML HUD → 안내 카드 → 패널

> 요정을 머리 원보다 아래 레이어에 두는 이유: 학생의 머리가 화면 가장자리로 가도 머리 원이 요정에 가려지지 않아야 한다.

## 2. 투척 캐릭터 (심술 도깨비) — 이번 설계의 중심

### 2-1. 배치

가장자리 5곳에 고정한다. 몸의 약 60%만 무대 안으로 들어오고 나머지는 화면 밖으로 걸친다(무대 안쪽을 가리지 않기 위함).

| 자리 | 위치 (단위계) | 그림 방향 | 크기(무대 높이 대비) |
|---|---|---|---|
| A 상단 좌 | x = aspect × 0.18, y = 0.07 | 오른쪽 보기(원본 반전) | 0.18 |
| B 상단 중앙 | x = aspect × 0.50, y = 0.05 | 정면에 가깝게(원본) | 0.18 |
| C 상단 우 | x = aspect × 0.82, y = 0.07 | 왼쪽 보기(원본) | 0.18 |
| D 좌측 중단 | x = aspect × 0.045, y = 0.42 | 오른쪽 보기(원본 반전) | 0.16 |
| E 우측 중단 | x = aspect × (1 − 0.045), y = 0.42 | 왼쪽 보기(원본) | 0.16 |

- 원본 그림은 **왼쪽을 보는 자세** 한 벌만 만들고, 좌측 요정들은 코드에서 `scale(-1, 1)`로 반전한다. 이미지 수를 절반으로 줄이기 위한 결정이다.
- 세로 화면(aspect ≈ 0.72)에서는 D·E를 y = 0.34로 올리고 크기를 0.14로 줄인다. 좁은 화면에서 머리 원과 겹치는 것을 막는다.
- 손 좌표(공이 떠나는 지점)는 각 자리마다 그림 중심 기준 오프셋으로 정의한다. 기본값: 바라보는 방향으로 그림 너비의 0.34, 아래로 그림 높이의 0.06.

### 2-2. 투척 사이클 (공 1개 = 1사이클)

| 단계 | 길이 | 요정 동작 | 공 | 학생이 받는 신호 |
|---|---|---|---|---|
| `idle` | 상시 | 0.9초 주기로 몸이 위아래 2% 들썩, 3초마다 눈 깜빡 | 없음 | — |
| `aim` | **0.45초** (상위 단계에서 0.28초까지 단축) | 몸을 뒤로 젖히고 팔을 뒤로. 이 요정만 밝기 100%, 나머지는 70%. 발밑에 **경고 삼각형**이 0→1로 커짐 | 손 안에서 공이 0→정상 크기로 커짐 | **"다음은 여기"** ← 가장 중요한 정보 |
| `throw` | 0.12초 | 팔을 앞으로 뻗고 몸이 앞으로 기움. 발밑에 먼지 퍼프 3개 | **손 좌표에서 공 생성**. 진행 방향으로 흐릿한 궤적선 0.3초 | "왔다" |
| `recover` | 0.35초 | throw 자세에서 idle 자세로 선형 복귀 | — | — |

- 공은 반드시 **요정 손 좌표에서 생성**해 둥지 중심 근처(둥지 반지름의 55% 안쪽 임의점)를 향해 직선으로 날아간다.
- 같은 요정은 `recover`가 끝나야 다음 사이클에 들어간다. 서로 다른 요정은 동시에 `aim` 상태일 수 있다.
- 난이도를 올릴 때 **예고 자체를 없애지 않는다.** `aim` 길이만 줄인다. 예고가 사라지면 "운으로 죽는 게임"이 된다.
- 공 종류는 요정이 들고 있는 물체로 구분한다. 요정 그림은 한 벌이고, 손에 든 물체만 코드로 바꿔 그린다.

### 2-3. 요정과 공의 대응

| 던지는 쪽 | 날아오는 것 | 화면 표시 | 속도 | 점수 |
|---|---|---|---|---|
| 심술 도깨비 (기본 크기) | 돌멩이 | 회색 원, 표시 없음 | ×1.00 | 10 |
| 심술 도깨비 (기본 크기) | 바람돌 | 붉은 원 + `»` + 긴 꼬리 | ×1.55 | 20 |
| 심술 도깨비 (1.35배 확대) | 큰 바위 | 보라 큰 원 + `●` | ×0.66 | 30 |
| 심술 도깨비 + 반짝임 효과 | 황금알 | 금색 원 + `★` | ×1.18 | 60 |
| **착한 다람쥐** (상단 중앙에만 등장) | 회복 열매 | 초록 원 + `＋` | ×0.82 | 알 +1 |

- 큰 바위를 던지는 요정은 **그림을 키워서** 표현한다. 덩치가 커 보이면 "느리지만 아프다"가 설명 없이 읽힌다.
- 회복 열매는 다람쥐가 미안한 표정으로 **굴려 보낸다**. 유일하게 착한 캐릭터라 색(초록)·기호(`＋`)·캐릭터 세 가지로 구분된다.
- 색만으로 구분하지 않는다는 접근성 규칙을 요정 단계에서 한 번 더 지킨다.

## 3. 머리 원

- 중심: 양 귀의 중점. 한쪽 귀만 보이면 코와 그 귀의 중점. 모두 안 보이면 직전 위치를 최대 0.9초 유지.
- 반지름 = 어깨 너비 × 0.30, `0.07 ~ 0.12`로 제한. **멀리 서면 자동으로 작아진다.**
- 모양: 2겹. 바깥은 청록(`#38bdf8`) 굵은 링 + 발광, 안쪽은 같은 색 16% 채움 + 위쪽 1/3에 흰 하이라이트 → **투명 헬멧**으로 읽히게 한다.
- 닿는 순간 0.12초: 링이 흰색으로 번쩍 + 두께 1.6배 + 닿은 지점에서 파티클 8개. 어디에 맞았는지 즉시 보인다.
- 글자: 2인용일 때만 링 위에 작게 `P1` / `P2`. 1인용은 글자를 넣지 않는다(영상을 덜 가린다).
- 인식이 끊기면 링이 점선으로 바뀌고 상단에 `머리를 찾는 중` 안내가 뜬다. 1.6초 넘게 안 보이면 자동 일시정지.
- 판정은 보이는 원 그대로다. 보이는 것과 판정이 다르면 학생이 규칙을 배울 수 없다. 다만 빠르게 지나가는 공을 놓치지 않도록, 직전 프레임과 현재 프레임의 머리 중심을 이은 **선분**과 공의 이동 선분을 함께 본다.

## 4. 둥지와 꼬물이

### 4-1. 배치

- 중심 (가로 중앙, 세로 0.76). 지켜야 할 원의 반지름 0.135.
- 경계는 점선 원. 평상시 하늘색, 실점 직후 0.7초는 분홍.
- **둥지 원(0.135) > 머리 원(0.07~0.12)** 이므로, 둥지에 머리를 붙이고 버텨도 공이 알에 먼저 닿는다. 길목으로 나가야만 막힌다. 이 관계는 규칙의 핵심이므로 상수를 바꿀 때 반드시 유지한다.
- 머리 원이 둥지 원 안에 1.3초 이상 머물면 안내: `둥지에 붙어 있으면 못 막아요 · 공이 오는 길목으로`

### 4-2. 꼬물이의 상태 반응

| 상황 | 반응 |
|---|---|
| 평상시(알) | 1.4초 주기로 숨 쉬듯 2% 커졌다 작아짐. 2초마다 `Zzz` 1개가 위로 떠올라 사라짐. 눈 감김 |
| 평상시(부화 후) | 같은 호흡. **눈동자가 가장 가까운 공을 따라 움직임** (귀여움 + 위험 방향 힌트) |
| 공이 들어옴(실점) | 눈 번쩍 → 0.25초 좌우 흔들림 → 금 1개 추가 → 0.8초 울먹(눈물 1방울). 경계선 분홍 |
| 머리로 막음 | 0.2초 동안 눈을 반짝 (콤보 5 이상이면 하트 1개) |
| 남은 시간 5초 이하 | 알이 들썩이는 주기가 2배 빨라짐 → "곧 나온다"는 예고 |
| 회복 열매를 받음 | 금 1개 사라지고 `냠!` 말풍선 |

### 4-3. 부화 연출 (2.8초, 단계 클리어 시)

| 구간 | 화면 |
|---|---|
| 0.00~0.90초 | 날아오던 공이 전부 바깥으로 튕겨 날아감. 요정들이 놀라 멈칫(idle 고정). 알이 점점 빠르게 흔들리고 금이 쩍쩍 늘어남. 효과음 음높이 상승 |
| 0.90~1.30초 | 껍질 터짐. 껍질 조각 12개가 파티클로 흩어지고 흰 플래시 1프레임 |
| 1.30~2.00초 | 꼬물이가 작게 나타나 1.15배까지 튀었다가 제자리로(오버슈트) |
| 2.00~2.80초 | 꽃가루 22개, 말풍선 `삐약!`, 화면 중앙에 `부화 성공! +300점`, 알 칸 1개 회복 |

이후 `3단계 시작!` 메시지와 함께 1.2초 뒤부터 첫 요정이 `aim`에 들어간다.

### 4-4. 성장 단계별 모습

| 단계 클리어 후 | 모습 | 대사 | 능력 |
|---|---|---|---|
| 1단계 → | 갓 깨어난 꼬물이. 머리에 깨진 껍질 모자 | `삐약!` | — |
| 2단계 → | 껍질 모자 벗고 작은 날개가 돋음 | `날개가 생겼어!` | — |
| 3단계 → | 날개가 커지고 콧김에 작은 불꽃 | `훗!` | **7초마다 가장 가까운 공을 불로 태움 (+15점)** |
| 4단계 이후 → | 같은 모습에서 크기 +6%씩(최대 1.3배) | `또 자랐어!` | 불 간격 0.5초씩 단축(최소 5초) |

3단계의 "지키던 대상이 나를 도와주기 시작한다"가 이 게임에서 가장 가치 있는 보상이다. 점수 보너스보다 이 순간이 먼저 오게 단계 길이를 짠다.

## 5. HUD

### 5-1. 부화 게이지 (상단 중앙, 화면의 1순위 정보)

```text
      ┌ 부화까지 23.4초 ─────────────┐
      │▓▓▓▓▓▓▓▓▓▓▓░░░░░░░░░░░░░░░░░░│   ← 남은 시간 비율로 줄어듦
      │      2단계  ·  알 ● ● ○      │
      └─────────────────────────────┘
```

- 바 폭 `clamp(240px, 26vw, 340px)`, 높이 14px, 테두리 2px.
- 남은 5초부터 바가 금색으로 0.4초 주기 깜빡 + 알림음. 소리를 꺼도 깜빡임으로 알 수 있다.
- `알 ●●○`는 남은 생명. 모양(채움/점선)과 개수로 구분하고 색에 의존하지 않는다.

### 5-2. 좌·우 수치

- 좌상단 `점수` — 숫자 크기 `clamp(34px, 4.4vw, 50px)`, 천 단위 쉼표
- 우상단 `콤보` — 5 이상이면 카드 배경이 금색으로 바뀜
- 가로 700px 이하에서는 라벨(`점수`/`콤보`)을 숨기고 숫자만 남긴다

### 5-3. 방향 경고

요정이 `aim`인 동안 그 방향의 무대 테두리 안쪽에 24px 폭의 붉은 그라데이션이 켜진다. 경고 삼각형과 중복 표시라서, 색각 이상이 있어도 삼각형으로 알 수 있다.

## 6. 단계와 점수

| 단계 | 버틸 시간 | 공 속도 | aim 길이 | 투척 간격 |
|---|---|---|---|---|
| 1 | 35초 | ×1.00 | 0.45초 | 기준값 |
| 2 | 40초 | ×1.09 | 0.41초 | ×0.88 |
| 3 | 45초 | ×1.18 | 0.37초 | ×0.77 |
| 4 | 50초 | ×1.27 | 0.33초 | ×0.68 |
| 5 | 55초 | ×1.36 | 0.30초 | ×0.60 |
| 6 이상 | 60초(상한) | +0.09씩(최대 ×1.9) | 0.28초(하한) | ×0.88^(단계−1), 최소 360ms |

점수 = 튕긴 공 점수 + 콤보 보너스(`min(콤보,12) × 2`) + 생존 5점/초 + **단계 보너스 300 × 단계**

난이도 선택(쉬움/보통/어려움)은 기준 속도와 투척 간격에만 곱한다. 단계 구조는 동일하다.

| `throw` | 툭 | |
| 머리로 튕김 | 공 종류별 음높이(돌 520 / 바람돌 700 / 바위 300 / 황금 880Hz 아르페지오) | |
| 실점 | 둔탁한 저음 + 꼬물이 울음 | |
| 남은 5초 | 0.4초 주기 알림음 | |
| 부화 | 상승 아르페지오 → 팡파르 | |
| 배경음악 | Am–F–C–G 4마디 반복, 단계마다 BPM +7 (102 → 최대 152) | 효과음보다 작게 |

소리는 기본 켜짐, 상단 바 버튼으로 즉시 끄고 켤 수 있으며, 꺼도 모든 진행을 화면만으로 이해할 수 있어야 한다.

## 8. 화면 단계(패널)

`intro → loading → ready → countdown → playing ⇄ paused → hatching → playing … → result`

| 패널 | 내용 |
|---|---|
| 시작 | 제목, 상황 소개 3줄, 인원(혼자/둘이 협동), 속도(쉬움·보통·어려움), 영상 보기, 반사선 보기, 조작 안내, 개인정보 문구, `카메라로 시작` / `키보드·터치로 시작` |
| 로딩 | 진행 바 + "처음 한 번만 받습니다" 안내 |
| 준비 | 인식 인원 수, 인식 FPS, `머리에 원이 생기면 준비 완료` 안내, `바로 시작` / `영상 숨기기` / `돌아가기` |
| 일시정지 | `계속하기` / `키보드·터치로 바꾸기`(인식 실패 시) / `처음으로` |
| 부화 | 패널 없이 무대 위 연출로만 진행 |
| 결과 | 도달 단계, 총 버틴 시간, 튕겨낸 공, 최고 콤보, 최종 점수, 이번 수업 기록 상위 5, `같은 사람 다시` / `다음 도전자 →` / `처음으로` |

시작 화면 상황 소개 문구(확정안):

> 둥지에 남은 마지막 알, **꼬물이**.
> 심술 도깨비들이 사방에서 돌을 던집니다.
> **부화까지 35초**, 머리로 막아 주세요.

## 9. 대체 경로와 안전장치

- 카메라 권한 거부·카메라 없음 → 오류 화면에서 `키보드·터치로 계속`. 머리 원을 드래그하거나 P1 `WASD` / P2 방향키로 움직인다.
- 인식이 1.6초 이상 끊기면 자동 일시정지하고, 점수를 그대로 둔 채 키보드·터치로 바꿀 수 있다.
- 영상은 기본으로 보이고 언제든 끌 수 있으며, 꺼도 인식과 진행은 계속된다.
- 영상과 좌표는 기기 밖으로 나가지 않는다. 저장·전송 기능을 넣지 않는다.
- 기록은 메모리에만 남고 새로고침하면 사라진다. 이름 대신 `도전자 1, 2, 3…`만 쓴다.
- 다른 탭으로 이동하면 일시정지하고 배경음악과 예약 음표를 멈춘다.

## 10. 완료 기준

- 머리 원이 카메라 영상 속 머리 위에 1:1로 겹치고, 보이는 원과 판정 원이 같다.
- 요정의 `aim` 동작을 보고 다음 공의 방향을 미리 알 수 있다. 공은 요정의 손에서 출발한다.
- 둥지에 머리를 붙이고 버티는 전략이 통하지 않는다.
- 제한 시간을 버티면 부화 연출이 재생되고 다음 단계로 이어지며, 단계 보너스가 점수에 더해진다.
- iPad A16 가로·세로에서 요정 5마리, 머리 원, 둥지, 부화 게이지가 겹치거나 잘리지 않는다.
- 콘솔 오류가 없고, 재시작·일시정지에서 타이머와 배경음악이 중복되지 않는다.
