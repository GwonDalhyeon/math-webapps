# 알을 지켜라! — UI 상세 설계

웹앱 위치: `icebreaking/egg-guardian/index.html`
이미지 제작 매니페스트: [`2026-11-23-head-shield-defense-art-manifest.md`](./2026-11-23-head-shield-defense-art-manifest.md)

대상: 일반계 고등학교 전체 학생, 첫 수업·모둠 활동 아이스브레이킹
기기 기준: iPad A16 가로 `1180×820` CSS px 우선, 세로 `820×1180`도 깨지지 않을 것. 교실 프로젝터/전자칠판 공유.

## 0. 이 설계가 바꾸는 것

| 항목 | 이전 | 이번 설계 |
|---|---|---|
| 머리 판정 원 | 중립 위치 대비 2.1~2.5배 증폭해 둥지 둘레에 따로 그림 | **카메라 영상 속 실제 머리 위에 1:1로** 그림. 보이는 원 = 판정 원 |
| 둥지 위치 | 하단 중앙(세로 72%) | **화면 정중앙** (`NEST_Y = 0.5`, `x = aspect × NEST_X_RATIO`, `NEST_X_RATIO = 0.5`), 반지름 `0.135` 유지 |
| 공 생성 | 화면 밖에서 소리 없이 생김 | **가장자리의 투척 캐릭터가 조준 → 던지는 동작**으로 손에서 생성 |
| 목표 | 오래 버티기(끝 없음) | **제한 시간을 버티면 부화 → 다음 단계**. 단계 보너스가 점수의 중심 |
| 지킬 대상 | 무표정한 알 | **꼬물이** — 숨 쉬고, 공을 눈으로 따라보고, 자라며, 4단계부터 도와줌 |

핵심 의도: "가만히 있으면 안 막힌다"와 "다음 공이 어디서 오는지 미리 보인다"를 **규칙 설명이 아니라 화면으로** 전달한다.

## 1. 화면 전체 구조 (한 화면, 스크롤 없음)

```text
┌ 상단 바: 목록 · 제목 · 소리 · 일시정지 ─────────────────────────┐
│ 점수                   부화 게이지                    콤보      │
│                  입력 모드 · 현재 공격 패턴                    │
│                         위쪽 요정                              │
│                                                               │
│ 왼쪽 요정         머리 원 → [중앙 둥지·알]          오른쪽 요정 │
│                                                               │
│                         아래쪽 요정                            │
└───────────────────────────────────────────────────────────────┘
```

1단계의 고정 배치 예시다. 2단계부터는 출현 지점이 바뀌고, 3단계부터는 경로를 따라 이동한다.

좌표계는 **무대 높이를 1로 보는 단위계**를 쓴다. x는 0~화면비(aspect), y는 0~1. 가로로 긴 화면에서도 원이 찌그러지지 않는다.

레이어 순서(아래→위): 카메라 영상 → 어둡게 덮는 막(투명도 34%) → 동심원 안내선 → 둥지·꼬물이 → 공 → **투척 요정** → 머리 원 → 파티클 → HTML HUD → 안내 카드 → 패널

> 요정을 머리 원보다 아래 레이어에 두는 이유: 학생의 머리가 화면 가장자리로 가도 머리 원이 요정에 가려지지 않아야 한다.

## 2. 투척 캐릭터 (심술 도깨비) — 이번 설계의 중심

### 2-1. 배치

공격 캐릭터는 요정으로 표시한다. 1단계는 위·오른쪽·아래·왼쪽 가장자리의 고정 요정 4명이며 회복 다람쥐는 별도 아군이다. 기존 이미지 10장은 파일을 변경하지 않고 재사용하며 새 이미지를 생성하지 않는다. 2단계는 가장자리 임의 위치에서 등장(360ms)해 조준·투척·회복(350ms) 후 퇴장(250ms)한다. 3·4단계는 가장자리에서 360ms 등장한 뒤 700~1100ms 이동하고, 최소 450ms 조준한다(조준 마지막 220ms 정지). 이어 throw 120ms, recover 350ms, 퇴장 250ms. 4단계 이후에는 중앙 둥지를 피해 화면 안쪽 외곽 직사각형 경로까지 이동 범위를 넓힌다. 상단 이동 경로는 HUD 아래로 두어 HUD를 가리지 않는다. 모든 단계에서 위·오른쪽·아래·왼쪽 공격을 섞고 HUD에 현재 공격 패턴을 표시한다.

| 단계 | 배치·행동 |
|---|---|
| 1 | 위·오른쪽·아래·왼쪽 경로의 중간에 고정 요정 4명 |
| 2 | 네 방향을 섞은 큐에서 출현 변을 정하고, 그 변의 12~88% 지점 중 임의 위치 선택 |
| 3 | 가장자리 직사각형 둘레를 초당 0.17(무대 높이 단위) 속도로 시계/반시계 이동 |
| 4 이상 | 중앙 둥지를 피한 안쪽 직사각형 둘레를 초당 0.23 속도로 이동 |
| 아군 | 별도 다람쥐 1개를 재사용하며 회복 열매를 줄 때만 상단에 등장 |

- 그림 높이 기준은 `min(0.11, aspect × 0.12)`, 큰 바위 요정만 1.35배. 몸 전체가 무대 안에 들어가게 여백을 둔다.
- 상단 경로는 HUD 아래, 나머지는 가장자리 여백 안으로 잡는다. 안쪽 경로는 최대 0.12만큼 좁히되, 좁은 화면에서도 둥지와 그림이 겹치지 않도록 제한한다.
- 출현 후보는 다른 보이는 요정과 겹치지 않는 곳을 최대 16번 찾고, 자리가 없으면 출현을 미룬다.
- 방향 큐는 **출현 방향**의 편중을 줄인다. 이동 중 모서리를 돌면 실제 투척 방향은 출현 방향과 달라질 수 있다.

- 기존 크기의 이미지 10장을 재사용하며 새 이미지를 생성하지 않는다. 좌우 방향은 코드에서 반전해 표현한다.
- 검증 대상 viewport는 가로 `1180×820`, 세로 `820×1180`, 모바일 `390×844`이며 구현 후 확인한다.
- 손 좌표(공이 떠나는 지점)는 각 자리마다 그림 중심 기준 오프셋으로 정의한다. 기본값: 바라보는 방향으로 그림 너비의 0.34, 아래로 그림 높이의 0.06.

### 2-2. 투척 사이클 (공 1개 = 1사이클)

| 단계 | 길이 | 요정 동작 | 공 | 학생이 받는 신호 |
|---|---|---|---|---|
| `hidden` | 2단계 이후 대기 | 그림과 판정 없음 | 없음 | 다음 출현을 기다림 |
| `idle` | 1단계 대기 | 몸이 위아래 2% 들썩 | 없음 | 고정 위치를 익힘 |
| `appearing` | 360ms | 서서히 나타남 | 없음 | 출현 위치 확인 |
| `moving` | 3단계 이상 700~1100ms | 외곽 경로 이동 | 없음 | 이동 방향 확인 |
| `aim` | 1단계 450ms, 2단계 410ms, 이동단계 최소 450ms | 둥지 쪽 경고 삼각형, 현 위치에서 둥지로 향하는 방향선, 4방향 테두리 경고 | 손 안에 공 표시 | 다음 공격 방향 예고 |
| `throw` | 120ms | 투척 동작 | 투척 순간 손 좌표에서 공 생성, 중앙 둥지를 향해 직선 비행 | 공격 실행 |
| `recover` | 350ms | 대기 자세로 복귀 | — | — |
| `leaving` | 250ms | 2단계 이후 및 다람쥐가 서서히 사라짐 | — | 투척 완료 |

- 공은 반드시 **투척 순간의 손 좌표에서 생성**해 중앙 둥지를 향해 직선으로 날아간다. 속도 상한에서도 반응 여유는 최소 900ms다. 2단계 이상 투척 간격은 기준값 × `0.65~1.35`로 불규칙하게 하고, 네 방향을 섞은 큐로 특정 방향 편중을 막는다. 이동 단계 조준은 최소 450ms이며 3단계 이후에는 투척 직전 220ms 멈춘다. 일시정지·부화·재시작 때 이동과 출현 예약을 정지/초기화한다.
- 같은 요정은 1단계에서는 `recover`, 이후에는 퇴장까지 끝나야 다음 사이클에 들어간다. 서로 다른 요정은 동시에 `aim` 상태일 수 있다.
- 이동 단계는 난이도와 관계없이 조준 예고를 최소 450ms 유지한다. 2단계는 고정된 출현 지점에서 410ms 조준한다.
- 공 종류는 요정이 들고 있는 물체로 구분한다. 요정 그림은 한 벌이고, 손에 든 물체만 코드로 바꿔 그린다.

### 2-3. 요정과 공의 대응

| 던지는 쪽 | 날아오는 것 | 화면 표시 | 속도 | 점수 |
|---|---|---|---|---|
| 심술 도깨비 (기본 크기) | 돌멩이 | 회색 원, 표시 없음 | ×1.00 | 10 |
| 심술 도깨비 (기본 크기) | 바람돌 | 붉은 원 + `»` + 긴 꼬리 | ×1.55 | 20 |
| 심술 도깨비 (1.35배 확대) | 큰 바위 | 보라 큰 원 + `●` | ×0.66 | 30 |
| 심술 도깨비 + 반짝임 효과 | 황금알 | 금색 원 + `★` | ×1.18 | 60 |
| **착한 다람쥐** (별도 아군) | 회복 열매 | 초록 원 + `＋` | ×0.82 | 알 +1 |

- 큰 바위를 던지는 요정은 **그림을 키워서** 표현한다. 덩치가 커 보이면 "느리지만 아프다"가 설명 없이 읽힌다.
- 회복 열매는 다람쥐가 미안한 표정으로 **굴려 보낸다**. 유일하게 착한 캐릭터라 색(초록)·기호(`＋`)·캐릭터 세 가지로 구분된다.
- 색만으로 구분하지 않는다는 접근성 규칙을 요정 단계에서 한 번 더 지킨다.

## 3. 머리 원

- 중심: 양 귀의 중점. 한쪽 귀만 보이면 코와 그 귀의 중점. 모두 안 보이면 직전 위치를 최대 0.9초 유지.
- 반지름 = 어깨 너비 × 0.30, `0.07 ~ 0.12`로 제한. **멀리 서면 자동으로 작아진다.**
- 모양: 2겹. 바깥은 청록(`#38bdf8`) 굵은 링 + 발광, 안쪽은 같은 색 16% 채움 + 위쪽 1/3에 흰 하이라이트 → **투명 헬멧**으로 읽히게 한다.
- 닿는 순간 0.12초: 링이 흰색으로 번쩍 + 두께 1.6배 + 닿은 지점에서 파티클 8개. 어디에 맞았는지 즉시 보인다.
- 글자: 2인용일 때만 링 위에 작게 `P1` / `P2`. 1인용은 글자를 넣지 않는다(영상을 덜 가린다).
- 인식이 끊기면 링이 점선으로 바뀌고 상단에 `머리를 찾는 중` 안내가 뜬다. 1.6초 넘게 안 보이면 자동 일시정지.
- 판정은 보이는 원 그대로다. 보이는 것과 판정이 다르면 학생이 규칙을 배울 수 없다. 다만 빠르게 지나가는 공을 놓치지 않도록, 직전 프레임과 현재 프레임의 머리 중심을 이은 **선분**과 공의 이동 선분을 함께 본다.

## 4. 둥지와 꼬물이

### 4-1. 배치

- 중심 (가로 중앙 `x=aspect×NEST_X_RATIO`, `NEST_X_RATIO=0.5`, 세로 `NEST_Y=0.5`). 지켜야 할 원의 반지름 0.135.
- 경계는 점선 원. 평상시 하늘색, 실점 직후 0.7초는 분홍.
- 둥지 반지름(0.135)은 머리 원(0.07~0.12)보다 크다. 중앙에 머리를 붙이고 버티면 사방의 돌을 막을 수 없으므로 길목으로 나가야 한다. 이동 요정도 이 영역을 침범하지 않는다.
- 공격은 중앙 둥지를 향해 날아오며, 학생은 이동해 투척 경로를 막는다.

### 4-2. 꼬물이의 상태 반응

| 상황 | 반응 |
|---|---|
| 평상시(알) | 1.4초 주기로 숨 쉬듯 2% 커졌다 작아짐. 2초마다 `Zzz` 1개가 위로 떠올라 사라짐. 눈 감김 |
| 평상시(부화 후) | 같은 호흡. **눈동자가 가장 가까운 공을 따라 움직임** (귀여움 + 위험 방향 힌트) |
| 공이 들어옴(실점) | 눈 번쩍 → 0.25초 좌우 흔들림 → 금 1개 추가 → 0.8초 울먹(눈물 1방울). 경계선 분홍 |
| 머리로 막음 | 0.2초 동안 눈을 반짝 (콤보 5 이상이면 하트 1개) |
| 남은 시간 5초 이하 | 알이 들썩이는 주기가 2배 빨라짐 → "곧 나온다"는 예고 |
| 회복 열매를 받음 | 금 1개 사라지고 `냠!` 말풍선 |

### 4-3. 부화 연출 (2.8초, 단계 클리어 시)

| 구간 | 화면 |
|---|---|
| 0.00~0.90초 | 날아오던 공이 전부 바깥으로 튕겨 날아감. 요정들이 놀라 멈칫(idle 고정). 알이 점점 빠르게 흔들리고 금이 쩍쩍 늘어남. 효과음 음높이 상승 |
| 0.90~1.30초 | 껍질 터짐. 껍질 조각 12개가 파티클로 흩어지고 흰 플래시 1프레임 |
| 1.30~2.00초 | 꼬물이가 작게 나타나 1.15배까지 튀었다가 제자리로(오버슈트) |
| 2.00~2.80초 | 꽃가루 22개, 말풍선 `삐약!`, 화면 중앙에 `부화 성공! +300점`, 알 칸 1개 회복 |

이후 다음 단계 시작 메시지와 함께 1.2초 뒤부터 첫 공격을 예약한다. 1단계는 바로 조준하고 이후에는 출현·이동을 거친다.

### 4-4. 성장 단계별 모습

| 단계 클리어 후 | 모습 | 대사 | 능력 |
|---|---|---|---|
| 1단계 → | 갓 깨어난 꼬물이. 머리에 깨진 껍질 모자 | `삐약!` | — |
| 2단계 → | 껍질 모자 벗고 작은 날개가 돋음 | `날개가 생겼어!` | — |
| 3단계 → 4단계 시작 | 날개가 커지고 콧김에 작은 불꽃 | `훗!` | 7초마다 가까운 공을 태움(+15점) |
| 4단계 클리어 이후 | 같은 모습에서 크기 +6%씩(최대 1.3배) | `또 자랐어!` | 불 간격 0.5초씩 단축(최소 5초) |

4단계에 불뿜기가 시작되어 지키던 대상이 플레이를 돕는 성장 보상을 준다.

## 5. HUD

### 5-1. 부화 게이지 (상단 중앙, 화면의 1순위 정보)

```text
      ┌ 부화까지 23.4초 ─────────────┐
      │▓▓▓▓▓▓▓▓▓▓▓░░░░░░░░░░░░░░░░░░│   ← 남은 시간 비율로 줄어듦
      │      2단계  ·  알 ● ● ○      │
      └─────────────────────────────┘
```

- 바 폭 `clamp(240px, 26vw, 340px)`, 높이 14px, 테두리 2px.
- 남은 5초부터 바가 금색으로 0.4초 주기 깜빡 + 알림음. 소리를 꺼도 깜빡임으로 알 수 있다.
- `알 ●●○`는 남은 생명. 모양(채움/점선)과 개수로 구분하고 색에 의존하지 않는다.

### 5-2. 좌·우 수치

- 좌상단 `점수` — 숫자 크기 `clamp(34px, 4.4vw, 50px)`, 천 단위 쉼표
- 우상단 `콤보` — 5 이상이면 카드 배경이 금색으로 바뀜
- 가로 700px 이하에서는 라벨(`점수`/`콤보`)을 숨기고 숫자만 남긴다

### 5-3. 방향 경고

조준 중 현 위치에서 중앙 둥지로 방향선을 긋고, 경고 삼각형과 4방향 테두리 경고를 함께 켠다. 예고음은 요정의 현재 x좌표에 따라 좌우 패닝한다. HUD에는 현재 공격 패턴을 글자로 표시한다.

## 6. 단계와 점수

| 단계 | 버틸 시간 | 공 속도 | aim 길이 | 투척 간격 |
|---|---|---|---|---|
| 1 | 35초 | ×1.00 | 0.45초 | 기준값 |
| 2 | 40초 | ×1.09 | 0.41초 | ×0.88 × 불규칙 계수 |
| 3 | 45초 | ×1.18 | 최소 0.45초 | ×0.77 × 불규칙 계수 |
| 4 | 50초 | ×1.27 | 최소 0.45초 | ×0.68 × 불규칙 계수 |
| 5 | 55초 | ×1.36 | 최소 0.45초 | ×0.60 × 불규칙 계수 |
| 6 이상 | 60초(상한) | +0.09씩(최대 ×1.9) | 최소 0.45초 | max(0.42, 0.88^(단계−1)) × 불규칙 계수 |

점수 = 튕긴 공 점수 + 콤보 보너스(`min(콤보,12) × 2`) + 생존 5점/초 + **단계 보너스 300 × 단계**

불규칙 계수는 0.65~1.35, 최종 투척 간격의 하한은 360ms다. 공 속도는 표의 배율을 적용하되 둥지까지 최소 900ms의 비행 여유를 보장하는 상한을 둔다. 난이도 선택(쉬움/보통/어려움)은 기준 속도와 투척 간격에만 곱한다. 단계 구조는 동일하다.

## 9. 대체 경로와 안전장치

- 카메라 권한 거부·카메라 없음 → 오류 화면에서 `키보드·터치로 계속`. 머리 원을 드래그하거나 P1 `WASD` / P2 방향키로 움직인다.
- 인식이 1.6초 이상 끊기면 자동 일시정지하고, 점수를 그대로 둔 채 키보드·터치로 바꿀 수 있다.
- 영상은 기본으로 보이고 언제든 끌 수 있으며, 꺼도 인식과 진행은 계속된다.
- 영상과 좌표는 기기 밖으로 나가지 않는다. 저장·전송 기능을 넣지 않는다.
- 기록은 메모리에만 남고 새로고침하면 사라진다. 이름 대신 `도전자 1, 2, 3…`만 쓴다.
- 다른 탭으로 이동하면 일시정지하고 배경음악과 예약 음표를 멈춘다.

## 10. 완료 기준 및 상태

- 머리 원이 카메라 영상 속 머리 위에 1:1로 겹치고, 보이는 원과 판정 원이 같다.
- 단계별 고정/출현/이동 공격 패턴과 HUD 표시가 구현된다. 네 방향 공격, 900ms 비행 여유, 이동단계 최소 450ms 조준, 경고 삼각형·방향선·4방향 테두리 경고, x좌표 기반 조준음 패닝을 확인한다.
- 일시정지·부화·재시작 시 이동·출현 예약이 정지/초기화되고 생존 점수 종료 중복 가산이 없다.
- 중앙 둥지가 공격 목표이며 네 방향에서 오는 공의 경로를 움직여 막을 수 있다.
- 제한 시간을 버티면 부화 연출이 재생되고 다음 단계로 이어지며, 단계 보너스가 점수에 더해진다.
- 가로 `1180×820`, 세로 `820×1180`, 모바일 `390×844`에서 주요 요소가 겹치거나 잘리지 않는지 확인했다. 실제 카메라·교실 기기 검증은 상태 문서의 남은 항목을 따른다.
- 콘솔 오류가 없고, 재시작·일시정지에서 타이머와 배경음악이 중복되지 않는다.
