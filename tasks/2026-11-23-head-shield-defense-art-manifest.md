## 1. 공통 시각 문법

스타일 기준은 이미 저장소에 있는 캐릭터
`icebreaking/upper-body-volleyball/assets/capybara-ai-cute-sample.png`이다. 새 캐릭터는 같은
세계관의 이웃처럼 보여야 한다.

1. **평면 2D 벡터풍**. 그라데이션·사실적 질감·3D 렌더·광원 반사 없음.
2. **굵고 둥근 진갈색 외곽선**(약 7~9px @480px). 선 끝은 둥글게.
3. 음영은 **본체색 + 한 단계 짙은 색 두 톤**만. 면으로 나누고 번지게 하지 않는다.
4. 얼굴은 **점 눈 + 짧은 선 입**처럼 최소 요소로. 흰 눈 하이라이트는 넣지 않는다.
5. 캐릭터는 **왼쪽을 바라본다**(코드에서 좌우 반전해 양쪽에 쓴다). 지정이 있는 항목만 예외.
6. 그림 안에 **글자·숫자·로고·말풍선·워터마크를 넣지 않는다.** 모든 문구는 웹에서 그린다.
7. 배경은 **자홍 단색 `#FF00FF`** 크로마키. 그림자·반사·바닥면을 그리지 않는다.
8. 무섭거나 공격적인 표정을 쓰지 않는다. 도깨비는 "심술궂지만 귀여운" 선을 지킨다.
9. 캐릭터가 실제 사람·실존 캐릭터·기존 상용 IP를 닮지 않게 한다.

**기존 파일 사용 조건 (후처리 지시 아님)**

- 현재 파일을 그대로 재사용하고 크기를 바꾸지 않는다.
- 자홍 배경 제거, 팔레트 변환 등 파일 재처리는 하지 않는다.
- 아래 이름은 현재 자산을 식별하기 위한 목록이며 새 파일 제작 요청이 아니다.

**검수 항목**

- 팔다리·귀·눈 개수, 손 모양이 세 프레임에서 일관된가
- `goblin-idle / aim / throw` 세 장의 **몸 크기와 발 위치가 같은가** (애니메이션으로 이어 붙이므로 기준선이 흔들리면 캐릭터가 떨린다)
- 왼쪽을 보고 있는가
- 글자·그림자·배경 잔여 픽셀이 없는가

## 3. 기존 이미지 10장 목록 (재사용 전용)

### A. 투척 캐릭터 (애니메이션 3프레임 + 아군 1장)

| 파일명 | 자세 지시 |
|---|---|
| `goblin-idle.png` | **대기**. 두 발로 서서 정면 아래쪽을 흘긋 본다. 양팔은 몸 옆에 자연스럽게 내리고, 왼손(앞쪽 손)에 아무것도 들지 않은 빈 주먹. 무릎을 살짝 굽혀 장난을 준비하는 기색. 몸통은 거의 수직 |
| `goblin-aim.png` | **조준**. 상체를 오른쪽(뒤쪽)으로 15도 젖히고, 던질 팔(앞쪽 왼팔)을 머리 뒤까지 크게 뒤로 당긴다. 손은 무언가를 쥐려는 듯 반쯤 벌린 주먹(쥔 물체는 그리지 않는다 — 공은 코드로 그린다). 반대 팔은 앞으로 뻗어 균형을 잡고, 앞발에 체중이 실려 발끝이 살짝 들림. 눈은 가늘게 뜨고 목표를 노려본다 |
| `goblin-throw.png` | **투척**. 상체를 왼쪽(앞쪽)으로 20도 기울이고, 던진 팔을 어깨 높이로 앞으로 쭉 뻗는다. 손은 방금 놓은 듯 손가락을 편 상태. 반대 팔은 뒤로 흐르고, 뒷발 뒤꿈치가 들려 있다. 입을 벌려 신난 표정 |
| `squirrel-toss.png` | **열매 건네기**. 앞발 두 개로 작은 열매를 감싸 쥐고 몸을 앞으로 숙여 굴려 보내려는 자세. 처진 눈썹과 어색한 미소로 "미안하지만 받아 줘" 하는 느낌. 열매는 단색 동그라미 하나로 단순하게. 꼬리는 위로 크게 말려 있다 |

> 세 프레임은 **발의 위치와 몸의 중심 높이를 동일하게** 유지한다. 코드에서 같은 좌표에 겹쳐 그린다.

|---|---|

| `hatchling-3.png` | **불을 익힌 꼬물이**. 날개가 1.4배 커지고, 콧구멍에서 작은 주황 불꽃 한 줄기가 비스듬히 위로 나온다. 당당하게 가슴을 편 자세. 불꽃은 그림의 10% 이하로 작게, 캐릭터를 가리지 않게. 몸 색·눈·비율은 앞 두 장과 동일 |

## 4. 구현 연결

기존 이미지 10장을 `icebreaking/egg-guardian/assets/`에서 그대로 재사용하고, 새 이미지를 생성하거나 파일을 교체하지 않는다. 구현 담당자가
UI 설계서에 따라 다음을 구현한다. 이미지가 아직 없으면 **같은 자리에 캔버스 도형으로 임시
대체**해 게임은 먼저 돌아가게 한다.

- 1단계 위·오른쪽·아래·왼쪽 고정 요정 4명(회복 다람쥐 별도), 2단계 가장자리 임의 출현 360ms → 조준 → 투척 120ms → 회복 350ms → 퇴장 250ms; 3·4단계는 가장자리 출현 360ms → 700~1100ms 이동 → aim 최소 450ms(마지막 220ms 정지) → throw 120ms → recover 350ms → 퇴장 250ms. 4단계 이후는 중앙 둥지를 피한 내부 직사각형 외곽경로로 확대하고, 상단 경로는 HUD 아래에 둔다.
- 모든 단계 네 방향 공격, 이동단계 aim 최소 450ms, 2단계 이상 간격 기준×0.65~1.35, 네 방향 혼합 큐, 투척 순간 손 위치에서 중앙 둥지로 발사, 속도 상한에서도 최소 반응 여유 900ms. 경고 삼각형·현재 위치에서 둥지로 방향선·4방향 테두리 경고, 현재 x좌표 기반 조준음 패닝, HUD 현재 패턴 표시.
- 머리 원 1:1 배치와 접촉 번쩍임
- 둥지 중앙 배치(`x=aspect×0.5`, `NEST_Y=0.5`, 반지름 0.135), 꼬물이 상태 반응과 시선 추적. 일시정지·부화·재시작 시 이동 및 출현 예약 정지/초기화.
- 부화 연출 2.8초와 단계 전환, 단계 보너스
- 제작 방식·참고 범위·후처리를 `icebreaking/egg-guardian/asset-notes.md`에 기록
