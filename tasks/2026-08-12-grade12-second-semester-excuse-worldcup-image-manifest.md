# 고3 2학기 수업 안 듣는 이유 월드컵 이미지 제작 매니페스트

상위 작업지시서: [`2026-08-12-grade12-second-semester-excuse-worldcup.md`](./2026-08-12-grade12-second-semester-excuse-worldcup.md)

## 1. 승인 기준이 되는 파일럿의 시각 문법

이 매니페스트는 아래 두 파일럿에서 확인된 방향을 고정한다.

- `G3-01 저 수학 필요 없는데요`: 뒤돌아서는 초라한 피규어, 발목을 잡는 포물선 밧줄과 수학책.
- `G3-38 저 오늘만 쉴게요`: 코발트 소파에 반쯤 파묻힌 피규어, 빈 달력 종이를 무한 배출하는 자동 연장기.

모든 후속 이미지는 다음의 공통점을 유지한다.

1. 실제 학생과 닮지 않는 한 명의 반복 등장용 가상 피규어를 쓴다. 풀어진 넥타이, 구겨진 셔츠·가디건, 헝클어진 머리, 어색한 표정과 자세를 기본값으로 한다.
2. 무대는 차갑고 깨끗한 옅은 회색 연구소 전시실이며, 둥근 코발트블루 받침대 위의 **하나의 과장된 물리적 상황**만 보여 준다.
3. 피규어는 장면의 오른쪽 또는 중앙에 두고, 왼쪽 또는 뒤쪽에 거대한 소품을 둔다. 같은 구도가 반복되면 소파형·도주형·대기형·기계형을 번갈아 쓴다.
4. 밝은 박물관 조명, 무광 피규어 재질, 코발트블루·회색·제한된 오렌지 포인트를 유지한다. 공포·음침한 실사·과한 애니메이션풍·제품 광고풍은 쓰지 않는다.
5. 이미지에는 문자, 숫자, 문장, 로고, 실제 학교 마크를 넣지 않는다. 카드 대사와 보조 태그는 웹에서 렌더링한다.
6. 위 18%·아래 15%는 차분한 음영이나 빈 벽으로 남겨 카드 텍스트와 결과 포스터를 위한 안전 영역으로 쓴다.

## 2. 한 장을 만드는 작업 단위

각 줄은 생성 프롬프트의 장면 부분이자 검수 기준이다. 이미지 한 장은 다음 단계를 모두 거쳐야 `enabled: true`가 된다.

1. **시안 생성**: 공통 프롬프트 + 표의 `장면 지시`로 1장 생성한다.
2. **즉시 판독 검수**: 문장을 보지 않아도 소품과 행동만으로 농담이 읽히는지 본다.
3. **통일성 검수**: 피규어, 배경, 조명, 받침대, 색 역할이 G3-01·G3-38과 맞는지 본다.
4. **제거·수정**: 생성된 문자·숫자·로고·실제 인물 닮은꼴·복잡한 배경·불필요한 두 번째 인물을 제거한다.
5. **웹 자산화**: 4:5로 크롭, `768×960 WebP`로 최적화, 파일명과 대체 텍스트를 매니페스트에 등록한다.
6. **대진 검수**: 실제 카드 화면에서 문장과 짝지어 보고, 장면이 너무 비슷한 상대와 만나도 헷갈리지 않는지 확인한다.

## 4. 배치와 승인 방식

### 배치 1: 기준 고정 4장

`G3-01`, `G3-05`, `G3-38`, `G3-52`를 먼저 완성한다. 서로 도주형·은퇴형·소파형·외주형으로 구도가 다르면서도 같은 전시실 세트처럼 보이면 승인한다. 승인 전에는 나머지 48장을 대량 생성하지 않는다.

### 배치 2: 본선 32장

상위 작업지시서에서 `우선`으로 표시한 32장을 8장씩 네 묶음으로 만든다. 각 묶음이 끝날 때마다 다음을 점검한다.

- 직전 묶음과 인물 비율·무대·조명이 달라지지 않았는가
- 문장 없이도 장면의 행동이 보이는가
- 장면이 같은 유형의 다른 카드와 시각적으로 충돌하지 않는가
- 모바일 카드에서 핵심 소품이 잘리지 않는가

### 배치 3: 확장 20장

본선 구현과 실제 교실 시연에서 자주 선택되는 카드를 먼저 넣고, 필요할 때 52개 전체 무작위 풀을 연다. 이미지가 없는 항목을 텍스트 카드로 임시 출전시키지 않는다.
