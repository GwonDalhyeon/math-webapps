## 2. 구현해 둔 것

### 2-1. 머리 원 (1:1)

- MediaPipe PoseLandmarker로 양 귀의 중점(없으면 코)을 잡아 **카메라 영상 속 머리 위에 그대로** 원을 그린다. 증폭 매핑과 중립 기준은 완전히 제거했다.
- 반지름 = 어깨 너비 × `HEAD_RADIUS_FROM_SHOULDER(0.30)`, `0.070~0.120`로 제한. 멀리 서면 작아진다.
- 보이는 원 = 판정 원. 닿으면 0.12초 흰색으로 번쩍이고 두께가 1.6배가 된다.
- 인식이 끊기면 점선으로 바뀌고, 1.6초 넘으면 자동 일시정지한다.

### 2-2. 둥지와 꼬물이

- 둥지는 **하단 중앙(세로 0.72)**, 반지름 `NEST_RADIUS(0.135)`. 머리 원보다 커서 둥지에 머리를 붙여도 돌이 알에 먼저 닿는다. 1.3초 이상 붙어 있으면 안내가 뜬다.
- 알은 숨 쉬듯 들썩이고 2초마다 `z`를 띄운다. 실점하면 놀란 표정 그림으로 바뀌고 금이 한 줄 늘어난다.
- 부화 후에는 눈동자가 가장 가까운 돌을 따라본다.

### 2-3. 투척 요정

- 가장자리 5자리(`THROWER_SLOTS`). 가로 화면은 상단 3 + 좌우 2, 세로 화면은 `PORTRAIT_SLOTS`로 게이지 아래로 내려 배치한다.
- 사이클: `idle → aim(0.45초, 단계가 오르면 0.28초까지 단축) → throw(0.12초) → recover(0.35초)`.
- `aim` 동안 손 안에서 돌이 자라고, 발밑에 경고 삼각형이 커지고, 그 방향 화면 테두리가 붉게 밝아지고, 좌/우로 패닝된 예고음이 난다.
- 공은 **요정의 손 좌표에서 생성**되어 둥지 안의 조금씩 다른 지점을 향해 직선으로 날아간다.
- 큰 바위를 던지는 요정은 1.35배로 커지고, 회복 열매는 상단 중앙의 다람쥐만 보낸다.

### 2-4. 단계와 점수

- 1단계 35초 → 40 → 45 → 50 → 55 → 60초(상한). `STAGE_TABLE` / `stageInfo()`에 속도·조준 시간·투척 간격을 함께 둔다.
- 시간을 버티면 `hatching`(2.8초): 돌이 전부 바깥으로 튕기고, 알이 흔들리다 껍질이 터지고, 꼬물이가 작게 나타나 튀었다가 제자리로, 꽃가루와 `부화 성공`.
- 단계 보너스 `300 × 단계`, 알 칸 +1(최대 3), 성장 대사(`삐약!` → `날개가 생겼어!` → `훗!` → `또 자랐어!`).
- **3단계부터 꼬물이가 7초마다 가장 가까운 돌을 태운다(+15점).** 간격은 단계가 오를수록 0.5초씩 줄어 최소 5초.
- 점수 = 튕긴 점수 + 콤보 보너스(`min(콤보,12)×2`) + 생존 5점/초 + 단계 보너스.

### 2-5. 그 밖

- 혼자 / 둘이 협동(머리 2개, 둥지·점수·알 공동), 난이도 3단계.
- 카메라 없이도 가능: 드래그 또는 P1 `WASD` / P2 방향키.
- 이번 수업 기록 상위 5(도전자 번호만, 메모리에만 저장), `다음 도전자 →`로 순서 교대.
- 효과음 11종 + 단계마다 BPM이 7씩 오르는 배경음악(최대 152).
- `반사선 보기` 토글: 튕길 때 법선·입사·반사를 0.7초 그린다.
- 그림이 없으면 캔버스 도형으로 대체해 게임이 계속 돌아간다.

## 3. 브라우저에서 확인한 것

- iPad A16 가로 `1180×820`: 넘침 0, 부화 게이지와 뱃지 줄 겹침 없음(겹쳐서 `.badge-row`를 106px로 내림), 둥지가 무대 안에 들어옴, 요정 5자리가 점수·콤보 카드와 겹치지 않음(겹쳐서 상단 좌우 요정을 `fx 0.22 / 0.78`로 옮김).
- iPad A16 세로 `820×1180`: 요정 5마리가 서로·게이지와 겹치지 않음(겹쳐서 `PORTRAIT_SLOTS` 추가), 머리 원·알·둥지·HUD 정상.
- 전체 흐름: 카운트다운 → 플레이 → 조준·투척 애니메이션 → 머리 원으로 튕김(점수·콤보 증가) → 실점(금 1줄·놀란 표정) → **부화 연출 → 2단계 전환(`부화까지 40.0초`, 알 3개 회복, 껍질 모자 쓴 꼬물이)** → 게임오버 → 결과·랭킹 → 일시정지·재개.
- 카메라 권한 거부 시 `키보드·터치로 계속` 대체 경로.
- 그림 10장 모두 `200 OK`로 로드(콘솔에 남아 있던 404는 Codex 제작 전 로드의 기록).

> 부화 확인은 1단계 시간을 6초로 잠시 줄여서 했고, **35초로 되돌려 두었다.**

## 4. 확인하지 못한 것 (중요)

1. **실제 카메라 동작 전부.** 브라우저 패널이 카메라를 막아 `getUserMedia` 이후 경로를 한 번도 실행하지 못했다. 머리 원이 실제로 머리에 겹치는지, 어깨 너비로 반지름이 적절히 잡히는지, 인식 FPS가 교실 기기에서 충분한지 미확인.
2. **둘이 협동 모드**의 좌우 사람 배정(P1/P2)과 두 원의 동시 판정.
3. **3단계 불 뿜기**(`tryFlame`)와 4단계 이상의 성장·속도. 3단계까지 가려면 약 2분을 버텨야 해서 미확인.
4. 교실 프로젝터·전자칠판 실물 화면.
5. 소리: 예고음 패닝이 실제로 방향 단서가 되는지.

## 6. 남은 작업 명세

### A. 실기기 카메라 검증 (최우선)

- **방법**: `npx serve -l 3456 .` 실행 후 일반 브라우저에서 `http://localhost:3456/icebreaking/head-shield-defense/` 를 열고 `카메라로 시작`.
- **확인 항목**
  1. 머리 원이 영상 속 머리에 겹치는가. 좌우로 움직일 때 어긋나지 않는가(거울 반전 일치).
  2. 1.5~2m에서 원의 크기가 돌을 막기에 적당한가. 너무 작으면 `HEAD_RADIUS_FROM_SHOULDER`(기본 0.30)를 0.34~0.38로 올린다.
  3. 준비 화면의 인식 FPS. 12 미만이면 `delegate: "GPU"`를 `"CPU"`로 바꿔 비교하고, 그래도 느리면 2~3프레임마다 추론하도록 `loop()`를 고친다.
  4. 1단계 35초를 평균적인 학생이 버틸 수 있는가. 못 버티면 `LEVELS[2].throwMs`를 1180 → 1350으로 올리거나 `STAGE_TABLE[1].seconds`를 30으로 줄인다.
  5. 돌이 오는 방향을 `aim` 동작만 보고 알 수 있는가. 모르겠다면 `aimMs`를 450 → 550으로 올린다.
  6. 정지·초기화 뒤 카메라 표시등이 꺼지는가.
- **완료 기준**: 위 6개를 모두 확인하고, 바꾼 상수를 이 문서 7절에 기록한다.

### B. 둘이 협동 모드 검증

- 두 사람이 카메라에서 2~3m 떨어져 좌우에 서고, 화면 왼쪽이 P1·오른쪽이 P2로 잡히는지 확인한다.
- 두 사람이 교차해 서면 배정이 뒤바뀐다. 뒤바뀌어도 게임이 성립하지만, 혼란스러우면 `updatePoses()`의 owner 배정에 직전 프레임 위치를 쓰는 추적을 더한다.
- **완료 기준**: 두 원이 동시에 판정되고, 한 사람이 화면을 벗어나도 자동 일시정지가 올바른 이름(P1·P2)을 말한다.

### C. 3단계 이상 진행 확인

- 1단계 시간을 잠깐 6초로 줄여(`STAGE_TABLE[1].seconds`) 3단계까지 빠르게 가 본 뒤 **반드시 35로 되돌린다.**
- 확인: 불 뿜기가 7초마다 가장 가까운 돌을 태우는가, 꼬물이 그림이 `hatchling-3`으로 바뀌는가, 4단계부터 크기가 커지는가, 배경음악 BPM이 올라가되 갑자기 커지지 않는가.
- **완료 기준**: 5단계까지 돌려 보고 타이머·음악·그림이 모두 단계와 맞는다.

### D. 목록 카드 이미지

- `docs/agent-guides/card-images.md` 절차를 따른다. 실제 웹앱을 열어 대표 장면(요정이 조준하는 순간 + 머리 원 + 둥지의 꼬물이)을 정하고 **시안을 사용자에게 제안한 뒤 승인받고** 제작한다.

- **완료 기준**: 다른 카드와 같은 형식이고, 카드 이미지만 보고도 "머리로 막는 게임"임이 읽힌다.

## 7. 교실에서 조정할 상수 (코드 상단에 모여 있음)

| 상수 | 기본값 | 의미 |
|---|---|---|
| `HEAD_RADIUS_FROM_SHOULDER` | 0.30 | 어깨 너비 대비 머리 원 반지름 |
| `HEAD_RADIUS_MIN / MAX` | 0.070 / 0.120 | 머리 원 반지름 한계 |
| `NEST_RADIUS` | 0.135 | 지켜야 할 원. **머리 원보다 커야 한다** |
| `NEST_Y` | 0.72 | 둥지의 세로 위치 |
| `LIVES` | 3 | 알 칸 |
| `STAGE_TABLE[n].seconds` | 35/40/45/50/55 | 단계별 버틸 시간 |
| `STAGE_TABLE[n].aimMs` | 450→300 | 조준 예고 길이 |
| `LEVELS[n].throwMs` | 1550/1180/900 | 난이도별 투척 간격 |
| `LEVELS[n].speed` | 0.27/0.33/0.39 | 난이도별 돌 속도 |
| `FLAME_FROM_STAGE` | 3 | 꼬물이가 돕기 시작하는 단계 |
| `POSE_LOST_PAUSE_MS` | 1600 | 머리를 놓쳤을 때 자동 일시정지까지 |

바꾼 값은 이 표에 날짜와 함께 덧붙인다.
