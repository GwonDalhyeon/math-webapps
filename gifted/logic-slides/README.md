# 0과 1로 판단하기 — 수업 화면

경상남도과학영재교육원 중학교 3학년 수학 학습지 04 「0과 1로 판단하기」로 하는 대면 수업(약 110분)의 교사용 투사 화면이다.
4:3, 1024×768을 기준으로 만들었으며 빌드 없이 정적 웹 서버에서 실행한다.

- 화면 52장(부록 2장 포함): 1. 기계는 어떻게 판단할까 → 2. 회로 읽기와 짓기 → 3. XOR을 만들어라 → 4. 직선 하나로 나누기 → 오늘의 정리 → 부록([더 해보기] 3-5·3-6).
- 방향키·스페이스·화면 밀기로 진행한다. 답 칸은 눌러서 열고, 화면 위 도구로 한꺼번에 열거나 닫는다. `B`는 화면 끄기, `Esc`는 전체 화면 목록이다.
- 회로판·대결판·좌표평면은 교사 태블릿에서 학생이 직접 눌러 회로와 직선을 그린다. 그린 것은 그 기기의 브라우저에만 저장되고 어디로도 보내지 않는다. 다음 반 수업 전에 화면 도구의 「기록 지우기」로 지운다.
- 활동 시계는 회로를 그리거나 쓰는 네 활동(2-3, 2-4-나 대결, 3-2·3-3, 정리 1)에만 있다. 숫자를 눌러 시작·멈춤, `↺`로 다시 맞춘다.
- 웹 서버에서 열면 삽화의 작은 움직임을 쓸 수 있다. WebGL을 쓸 수 없거나 파일을 직접 열면 원래 그림을 보여 준다.

학생이 활동한 뒤에 여는 답(예시답안)이 화면에 들어 있다. 평가에 쓰지 않는 수업이다. 교사용 발문·지도 내용, 개인정보, 제작 도구, 시안과 검토 캡처는 포함하지 않는다.
수업 전에는 실제 프로젝터와 태블릿에서 회로판 누르기, 직선 끌기, 화면 밀기, 어두운 장면의 밝기를 확인한다.
